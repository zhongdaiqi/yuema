# 应用日志记录说明

## 日志记录功能
应用现在具备了以下日志记录功能：

1. **崩溃异常记录** - 自动捕获并记录应用崩溃信息
2. **页面访问记录** - 记录用户访问的页面
3. **API调用记录** - 记录API调用情况
4. **用户操作记录** - 记录用户的关键操作

## 日志上传机制
- 应用启动时会立即上传本地缓存的日志
- 每30秒定期检查并上传本地日志
- 如果网络请求失败，日志会暂存在本地
- 本地日志最多保存100条记录

## 如何查看日志
1. 在应用中发生崩溃或错误时，相关信息会被自动记录
2. 日志会尝试上传到云端服务器
3. 如果云端上传失败，日志会保存在本地存储中

## 问题排查
如果应用仍然闪退，请检查：
1. 设备网络连接是否正常
2. 服务器地址是否正确配置
3. 控制台输出的详细错误信息
